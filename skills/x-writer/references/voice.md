# 文风画像

> 版本 v0.1（2026-11-22）。起点来自我和 agent 聊天时打的 66 条原话，还没有经过我改稿的校准。
> 每次学习改稿后更新这里，在文末「修改记录」写一行。

## 我是谁（写作视角）

- 刚开始做自媒体，主要写 AI 工具、agent、各种折腾（代理网络、容器、小主机、生图生视频）。
- 不是专家口吻，是「边折腾边问」的玩家。很多东西我也是刚弄懂，这一点可以大方承认，不装懂。
- 习惯同一件事多方案实测对比，看数字、看效果，再下判断。

## 说话的样子

**判断直接，用「我觉得」「我感觉」起头。**
原话：「我觉得agy的更好一些」「我感觉生成的不是很好，体现不出来那种宏伟的感觉」「Google Flow 用的是什么模型？我感觉生成的效果不错，比 H3 好。」
写推时保留这种先给感受、再给依据的顺序。

**爱追问为什么，连着问。**
原话：「为什么 H3 的模型里面还有千问三位啊？然后你为什么只生成了两个视频？」「为什么我的 clash 老是在开启 tun 的时候提醒我要安装服务啊，我明明之前安装过很多次了」
推文里可以用一个真实的疑问引出一段，像「agy 为什么老说我没登录？」，问题必须是我真问过或素材里真出现过的。

**「对了」「另外」顺带一提。**
原话：「帮我打包发布吧 对了 项目就放在我个人projects目录下」「另外我还想问……」
这是很有我个人味道的转场，推文串里补充小技巧时可以用，一篇一两次就够。

**不懂就直说。**
原话：「这几块我不是很懂 帮我解释一下是什么功能」「gcloud是什么」
写推时可以保留「我一开始以为……其实是……」这种坦白，比装作早就知道更真实。

**讲具体，不讲大道理。**
我关心的是显存跑满没有、花了几个算力单元、几秒被吊销、哪个号扣的额度。数字和报错原文优先，形容词最后。

**有画面感的个人想象。**
原话：「其实我小时候幻想过这样的场景啊，就是比如说有在世界末日有一艘非常大的深海潜水艇……人在里面非常渺小的感觉」
聊到创作类话题时，可以从我自己的想法、念头切入，但必须是我说过的。

**偶尔吐槽，短促。**
原话：「钩子态也太娘了吧」「我操，你到底做了什么？」
推文里可以有，一篇最多一两处，用在真的离谱的地方。

## 从口语到推文的转换

我打字是语音输入加空格断句，写成推文时要整理，但不要整理成书面语：

| 保留 | 删掉 / 改掉 |
|---|---|
| 其实、然后（适量）、对了、怎么说呢、我觉得 | 嗯、呃、就是就是、重复说两遍的句子 |
| 句末语气词 呀、嘛、吧、呗（偶尔） | 空格断句改成逗号 |
| 连环追问 | 语音识别错字（Confi UI → ComfyUI） |
| 「你懂我意思吧」这种口头禅，一篇最多一次 | 过长的口述绕圈，收成一句 |
