# X 平台格式

## 字数怎么算

- 普通账号单条上限 280「权重字符」。英文、数字、半角标点算 1，中文、日文、全角标点、emoji 算 2，所以纯中文大约 140 字。
- 链接不论多长都按 23 算。
- 用 `uv run scripts/x_length.py` 算，别靠目测。

## 几种形式

**单条**：一个点，一个细节，一个判断。适合「刚发现一个坑」「一个数字很反直觉」。

**推文串**：
- 第 1 条是钩子，交代我做了什么、规模多大、接下来讲什么，让人想点开。不写「🧵」。
- 中间每条一件事，尽量自成一体，单独被转发也看得懂。
- 命令和配置尽量短；太长的放长推或配图。
- 最后一条收尾加一句互动，不总结全文。

**长推**（X Premium 的长文）：
- 适合有来龙去脉、要贴命令和配置的内容。
- 段落短，一两句一段。
- 不加小标题，靠转场句推进；命令用代码块。

**X Article**（教程长文）：
- 写法见 genres.md。不写目录，因为它点不了也跳不过去。
- 编辑器支持标题、列表、引用、链接。不支持代码块和分隔线，「一键指令」用引用块。
- 一定要配一条钩子推，填在发布框的「说明文字」里，文章链接会自动附在后面。按单条的 280 上限计数，用 x_length.py 检查。
- 封面 5:2（1500×600）；正文截图位置写 `[图：截什么，证明什么]`，发布前要么换成真图，要么删掉。
- 篇幅以讲清楚为准，不凑字数；钩子推里写的字数要和正文实际字数一致。

**发布后改不了**：已发布的文章没有编辑入口，只能「取消发布，移至草稿」→ 改 → 再发布。再发布沿用原来的帖子，说明文字（钩子推）和受众设置都改不了。所以标题、钩子推、链接、字数都要在第一次发布前核对清楚。

## 开头

从具体的事起头，任选一种：
- 我做了什么：「用了一个多月 X，三台机器都装了一遍」
- 一个反直觉的数字：「5 条视频只花了 1.8 个算力单元」
- 一个真实的报错或疑问：「agy update 一直报 update already in progress」

不写背景铺垫，不写「最近很多人在问」，除非素材里真有。
