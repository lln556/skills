# 学习我的改动

目标：把我每次改稿的习惯沉淀进 voice.md 和 taboos.md，让下一次初稿更接近我会发出去的样子。

## 1. 存终稿

- 找到对应的 `samples/<日期>-<主题>/draft.md`。找不到就问我是哪篇。
- 把我发来的终稿原样存成同目录的 `final.md`，一个字都不改。我只给了推文链接、X 打不开的话，请我把文字贴过来。
- 终稿里如果有隐私信息，先提醒我，再决定存不存。

## 2. 对比

逐段对比 draft 和 final，只看我主动改的地方，记录成同目录的 `diff-notes.md`：

```markdown
| 位置 | 初稿 | 我的改法 | 可能的原因 |
|---|---|---|---|
| 第 3 条 | 修法是去掉明文 DNS | 我直接贴了配置片段 | 喜欢给能抄的东西 |
```

重点看这几类：
- 删掉的：哪些词、句式、段落被我删了（说明我不喜欢）。
- 加上的：我补了什么细节、口头禅、情绪、吐槽（说明初稿缺这个）。
- 改写的：同一个意思我换成了什么说法。
- 顺序：我有没有调整段落顺序、开头和结尾。

## 3. 归纳

- 只出现一次的改动，记在 diff-notes.md 里，不急着改规则。
- 同一类改动在 2 篇以上样本里出现，升级成规则：写进 voice.md 对应小节（附我终稿里的原句当例子）；属于「不要这样写」的，写进 taboos.md。
- 和现有规则冲突时，以我最近的改法为准，旧规则改掉或删掉，不要两条打架。
- 不从样本里抄具体经历和数字进规则，规则只描述「怎么说」。

## 4. 更新并汇报

- 更新 voice.md 文末「修改记录」，写一行：日期 · 样本 · 学到了什么 · 改了哪一节。
- voice.md 顶部的版本号小版本 +1（v0.1 → v0.2）。
- 回复我时用两三句话说清这次学到了什么、改了哪几条规则，让我确认。我说不对就撤回。
